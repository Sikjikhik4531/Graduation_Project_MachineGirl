# 기계소녀 (Machine Girl)

기계소녀가 로봇 군단과 싸우는 모바일 방치형 자동 전투 RPG입니다.
게임인재원 팀 프로젝트로 개발했고(2024.04 ~ 2024.11), 구글 플레이에 출시했으며, G-STAR 2024에서 시연했습니다.

- **기술:** Unity (URP), C#, DOTween, TextMeshPro
- **역할:** 클라이언트 프로그래머 (전투 · 성장 시스템)

## 담당 구현

- **행동 트리 기반 자동 전투 AI:** Selector · Sequence · Condition · Action 노드를 직접 구현
- **액션 로직과 스킬:** 최대 7칸 스킬 순환, 스킬 10종과 3단계 트라이포드
- **상태 이상과 원소 반응:** 프로토타입 패턴 기반 상태 이상 16종, 원소 반응 피해
- **몬스터와 스폰:** 몬스터 상태 머신, 9가지 스폰 방식, 원형 · 부채꼴 · 사각형 · 십자 · 선분 범위 판정
- **성장 시스템:** 등급 · 가중치 기반 제네릭 뽑기, 장비 합성, 능력치와 전투력 계산
- **전투 분석:** 스킬별 누적 피해, DPS, 기여도
- **구조와 연출:** 매니저 구조, 오브젝트 풀, 인게임 UI, 카메라 흔들림 · 줌 · 슬로모션

Firebase · Google Play Games 연동, 튜토리얼 · 퀘스트, Shader Graph 연출은 팀원이 담당했습니다.
